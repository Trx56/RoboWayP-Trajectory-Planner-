# Robo-WayP: Robotic Arm Trajectory Planner

Team project developed for Robotics and Automation engineering[cite: 1]. 

## Overview
An interactive simulation engine featuring analytical 3-DOF inverse kinematics (Elbow Up/Down configurations), workspace obstacle collision detection, and multi-polynomial trajectory interpolation[cite: 1, 13, 14].

## Features
- Analytical Inverse & Forward Kinematics for 3-link planar arms[cite: 1, 14].
- Quintic (5th-order) and Cubic (3rd-order) trajectory interpolation[cite: 1, 14].
- Workspace boundary and obstacle clearance checking[cite: 14].
